# 三国志 · 帝王本纪编年时间轴

基于陈寿《三国志》八卷帝王本纪（曹魏《武帝纪》《文帝纪》《明帝纪》《少帝纪》、蜀汉《先主传》《后主传》、东吴《孙破虏讨逆传》《吴主传》）构建的编年史料时间轴与原文精读应用。

## 主要功能

- **垂直编年时间轴**：覆盖东汉末年至三国归晋（公元 155–265 年，共 424 则史事），支持公元纪年与东汉、魏、蜀、吴、西晋年号对照。
- **阵营筛选与时代导览**：支持按魏、蜀、吴阵营过滤史料，并可快速跳转至「汉末风云」「官渡赤壁」「三国鼎立」「北伐中原」「天下归晋」等关键历史节点。
- **史料弹窗与原文跳转**：点击时间轴事件卡片可查看原句摘录与出处，支持一键跳转至对应卷目正文并自动定位高亮该段落。
- **视觉与动效**：黑金宣纸配色与低饱和矿物阵营印章，搭配动态画廊背景与 GSAP 滚动渐显效果。

## 技术栈

- **前端**：React 19, Vite, React Router, GSAP, Lucide React
- **数据处理**：Python（[fix_data.py](fix_data.py) 用于年代换算、事件标题清洗与重要度分级）

## 目录结构

```text
├── data/                       # 原始《三国志》分卷文本 JSON
├── frontend/
│   ├── public/data/
│   │   ├── timeline/           # 清洗后的八卷本纪时间轴索引 JSON
│   │   └── volumes/            # 前端按需加载的原文分卷 JSON
│   └── src/
│       ├── Timeline.jsx        # 垂直时间轴主视图与筛选导览
│       ├── VolumePage.jsx      # 卷目原文精读与段落高亮页
│       ├── GalleryBackground.jsx
│       └── index.css
├── fix_data.py                 # 时间轴索引生成与清洗脚本
└── README.md
```

## 本地运行

```bash
cd frontend
npm install
npm run dev
```

构建生产版本：

```bash
cd frontend
npm run build
```
